HawkSnap

像鹰一样准，一按就截

免费、纯本地的轻量截屏工具。区域 / 全屏截图、智能吸附、标注、OCR、贴图、 录屏（MP4 / GIF）、长截图、历史全文搜索——无账号、无云端、无遥测。

功能

点击卡片查看对应文档（入口、权限要求与已知限制）。

基础截图

F1 区域 / 全屏：冻结帧上拖拽框选，方向键 1px 微调、边缘磁吸、延时截图、多显示器各自覆盖层。

智能吸附

悬停即高亮光标下的元素或窗口，单击直接选中（元素 → 窗口 → 整屏三级回退），无需拖拽。需辅助功能授权。

标注编辑器

10 类工具：矩形 / 椭圆 / 箭头 / 画笔 / 荧光笔 / 马赛克 / 序号 / 文字 / 裁剪 / 选择，撤销重做无步数限制。

OCR 文字识别

中英双语本地识别（PP-OCRv4，纯本地推理），结果逐行复制 / 导出 txt，并回填历史全文检索。模型按需下载。

贴图 Pin

F2 把截图钉在桌面：置顶无边框窗口，拖拽移动、滚轮缩放、Ctrl+滚轮调透明度，多贴图级联错开。

录屏

F6 区域 / 整屏录制，MP4（H.264 + 系统声音）或 GIF 导出，录制中可开摄像头画中画与按键显示。

历史搜索

每次截图 / 录制 / 长截图自动入本地库，支持含 OCR 文本的中英文全文搜索、重新编辑、按类型管理。

浏览器插件

Chrome / Edge 整页（10000px+ 高保真）/ 可见区 / 区域截图，标注后复制下载，可选发送到桌面端历史。

平台支持

与 README「平台支持」一节同口径：只承诺验证过的，其余如实标注。

隐私与许可

无遥测，无账号

截图、历史、OCR、录屏全部纯本地：不上传、不采集、不要求注册。浏览器插件同样只截取 你显式触发（工具栏点击 / 快捷键）的页面，不后台采集、不上报。

OCR 模型按需下载

首次使用 OCR 时联网下载约 60MB 模型（官方 release 源，全程 SHA256 校验），此后离线可用； 引擎空闲 10 分钟自动释放内存。
