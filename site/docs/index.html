安装与授权、快捷键、功能入口速查、浏览器插件与常见问题。

安装

  1. 下载 dmg：前往 GitHub Releases 下载最新版 HawkSnap_*.dmg（macOS 12.3+，Intel / Apple Silicon 同包）。
  2. 安装：打开 dmg，把 HawkSnap 拖入「应用程序」，首次启动后常驻托盘（零窗口、后台待命），从托盘菜单打开主面板。
  3. 屏幕录制授权（首次截图必需）：

    首次按 F1 截图时 macOS 会弹窗请求「屏幕录制」权限，点允许并重启应用。若未弹窗或截图失败，前往 系统设置 → 隐私与安全性 → 录屏与系统录音，添加 HawkSnap 并开启，然后重启应用。

    macOS 14+ 未授权时抓屏可能静默返回壁纸画面而非报错——应用内置权限预检与系统设置深链引导（启动及截图时触发），若引导后仍未生效请按上文手动授权并重启。

  4. 辅助功能授权（智能吸附与按键显示）：

    悬停高亮 / 单击选中、以及录制中的按键显示需要「辅助功能」授权：系统设置 → 隐私与安全性 → 辅助功能 添加 HawkSnap。未授权时拖拽框选仍可正常使用，只是没有悬停高亮；按键显示不可用。

  5. F1 按键模式（媒体键兼容）：

    macOS 默认把 F1 当作亮度键。HawkSnap 自动兼容，但需二选一：① 系统设置 → 键盘 → 键盘快捷键 → 功能键 开启「将 F1、F2 等键用作标准功能键」；或 ② 保持默认（F1 = 亮度键），并按上文授予辅助功能权限（推荐，开箱即用， fn+F1 组合同样有效）。两者都不满足时应用启动会显示引导横幅。

快捷键

按键作用
F1截图：拖拽 = 框选区域，Enter / 双击 = 整屏快捷确认，Esc 取消
F2贴图：把最近一次截图（或剪贴板图像）钉在桌面
F6录屏：进入选区模式，拖拽 = 录该区域，Enter / 双击 = 整屏；悬浮条可暂停 / 恢复 / 停止
Esc取消截图 / 关闭贴图 / 退出选区
Enter确认选区（截图 / 录屏 / 长截图通用）
方向键微调选区 1px（Shift = 10px），贴近窗口边缘 8px 内自动磁吸
C框选中切换取色器（放大镜取色，点击复制 HEX / RGB）
⌘S长截图「完成」/ 编辑器保存

自定义热键

主面板 → 设置 → 全局热键：截图 / 贴图 / 录制三项可自定义，修改后立即生效；与其他应用冲突时保存失败并提示 （macOS 无公开 API 列出占用者，请自行排查）。F1 / F2 / F6 为出厂默认。

标注编辑器内快捷键

⌘Z / ⌘⇧Z 撤销 / 重做（无步数限制）、Delete 删除选中形状、⌘S 保存覆盖原图、双击文字形状重新编辑。

贴图 PinF2 / 托盘 / 主面板拖拽移动、滚轮缩放（10%–3200%）、Ctrl+滚轮调透明度（20%–100%）、Esc 关闭。

历史搜索托盘「主面板」→ 历史本地 SQLite 全文检索（含 OCR 文本）、查看 / 删除 / 重新编辑；上限 500 条自动裁剪。
浏览器插件浏览器工具栏整页 / 可见区 / 区域截图 + 标注 + 复制下载，可选发送到桌面端（见 下节）。

浏览器插件安装

MV3 扩展，支持 Chrome / Edge（同一份构建）。整页截图走 chrome.debugger 的 captureBeyondViewport（10000px+ 高页面保真，含懒加载图滚动等待）；使用期间页面顶部会出现浏览器调试横幅，截图结束即消失。

1. 获取并构建

插件以源码随仓库分发：从 Release 下载源码归档 HawkSnap-*-source.tar.gz（或克隆仓库），解出 plugin/ 目录后构建：

cd plugin
npm install
npm run build

产物在 plugin/dist/。构建只需 devDependency esbuild，运行时零依赖。

2. 加载已解压的扩展程序

  1. 打开 chrome://extensions（Edge：edge://extensions）；
  2. 右上角开启「开发者模式」；
  3. 点「加载已解压的扩展程序」，选择 plugin/dist 目录；
  4. 工具栏出现隼形图标 → 点击选择：整页截图 / 可见区域 / 区域截取。

3.（可选）发送到 HawkSnap 桌面端

经 Native Messaging 把标注后的截图直接送进桌面端历史。宿主名 com.hawksnap.app， 只允许你自己的扩展 ID 连接：

  1. 安装桌面端 HawkSnap ≥ 1.0.0（dmg 内含宿主二进制 hawksnap-host）；
  2. 从源码包解出 scripts/install-native-host.sh，在扩展设置页（或 chrome://extensions 的详情）查看扩展 ID（32 位 a–p 字符），执行：
./scripts/install-native-host.sh --ext-id 你的扩展ID

脚本会同时写 Chrome 与 Edge 的宿主 manifest（NativeMessagingHosts/com.hawksnap.app.json）。 之后在插件编辑器里点「发送到 HawkSnap」即可；宿主未注册 / 载荷超 4MB / 回执超时（30s）时自动降级为本地下载并提示原因。

隐私口径：插件只在你显式点击 / 快捷键触发时访问当前页面；不预授权任何站点（无 host_permissions）、不后台采集、不上报；与桌面端只在本机 stdio 通信，无网络通道。

FAQ

截图是黑屏 / 壁纸，权限弹窗没出现？

前往 系统设置 → 隐私与安全性 → 录屏与系统录音，为 HawkSnap 开启权限并重启应用。 macOS 14+ 未授权时可能静默返回壁纸画面；应用内的权限预检与深链引导会在启动 / 截图时提示。 智能吸附无高亮、按键显示不工作则是缺「辅助功能」授权（见安装一节）。

OCR 模型要下载多大？断网能用吗？

首次触发 OCR 时联网下载约 60MB（PP-OCRv4 mobile 三模型，官方 release 源 + SHA256 校验，进度条可见）， 之后完全离线可用；推理纯本地，识别结果不上传。引擎空闲 10 分钟自动卸载（单会话峰值内存约 580MB）。

Intel Mac 支持吗？

基础截图、智能吸附、标注、贴图、录屏 / GIF、长截图、历史等均支持（macOS 12.3+ Intel / Apple Silicon 同包）。 OCR 不支持 Intel macOS——ONNX Runtime 官方未发布 macOS x64 构建，Intel 机器上会明确报错而非静默失败。

历史和文件保存在哪？会传到云端吗？

全部纯本地：截图在 ~/Pictures/HawkSnap，录屏 / GIF 在 ~/Movies/HawkSnap， 历史索引为本地 SQLite（含 OCR 全文检索）。历史条目上限 500 条自动裁剪——录制条目只删索引行、保留视频文件。

长截图拼接被拒绝 / 被截断？

长截图只支持单轴纵向滚动；周期性内容（聊天气泡、同构瓦片）可能被拒绝拼接——宁可缺一段， 绝不产出重影图。画布硬上界 256MB / 高度 40000px，触顶即截断并提示；页面在动但内容不可测量时也会停止并提示。

有 Windows / Linux 安装包吗？

暂无。两个平台可编译、可跑测（CI 硬门），但截图能力未适配、未实测，录屏等 macOS 专属能力明确报错； 打包 / 签名 / 更新 feed 的跨平台分发口径另案裁定（见平台支持）。
