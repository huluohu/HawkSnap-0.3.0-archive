# HawkSnap

**像鹰一样准，一按就截。**

HawkSnap 是一款免费、纯本地的轻量级截屏工具，基于 Tauri 2 + Rust + React 构建——无账号、无云端、无遥测。

## 平台支持

| 平台 | 编译 | 采集能力（截图 / 录屏 / 贴图 / 长截图 / 按键显示） | 二进制分发 |
| --- | --- | --- | --- |
| macOS 12.3+（Intel / Apple Silicon） | ✅ | ✅ **功能完整** | ✅（当前唯一发布平台） |
| Linux（Ubuntu 22.04 / 24.04） | ✅（M4 跨平台重构后） | ❌ **尚未适配**——相关入口明确报错 | ❌ |
| Windows（Win10 1903+ / Win11） | ✅（同上） | ❌ **尚未适配**——同上 | ❌ |

**Linux / Windows 当前只保证「能编译、能跑测」**：macOS 专属的采集栈（ScreenCaptureKit / AVFoundation / AppKit 绑定）在这些平台上不存在，相关代码按 `#[cfg(target_os = "macos")]` 门控，并以**同名同签名**的平台桩替代——调用即返回明确错误（「该平台暂不支持」），**绝不静默假装成功**；历史库 / OCR / 编辑器 / 设置等与平台无关的部分照常可用。

真正的平台适配（Windows 抓屏与全局热键、Linux X11 录屏与窗口枚举、Wayland 走 portal 等，见设计文档 §6.3 平台验收矩阵）留待后续里程碑。

## 当前进度

M1 Plan A + Plan B + Plan C + Plan D 已完成；M2（标注 / OCR / 录屏）与 M3（区域录制 / GIF 导出 / 摄像头画中画 / 按键显示 / 长截图）已完成，当前版本 0.3.0。

Plan A——F1 截图闭环：

- 常驻托盘菜单「截图 (F1)」或全局热键 F1 触发截图；
- 在冻结帧覆盖层上拖拽框选（Enter / 双击确认，Esc 取消）；
- 确认后图像进入剪贴板，并保存到 `~/Pictures/HawkSnap`。

Plan B——智能吸附与交互增强：

- 动作浮条：框选后出现浮条，复制 / 保存 / 标注一键直达（Enter 默认复制，标注当前选区直进编辑器）；贴图 / OCR / GIF 按钮为占位（未启用，OCR 已在编辑器内提供）；
- 方向键微调 + 磁吸：选中后按方向键以 1px 微调选区（Shift 为 10px），贴近已有窗口边缘 8px 内自动吸附；
- 智能吸附：悬停即高亮光标下的元素或窗口，单击直接选中，无需拖拽（元素 → 窗口 → 整屏三级回退，即窗口 / 全屏模式）；
- 延时截图：托盘菜单「延时截图」可选 1 / 2 / 3 / 5 秒，倒计时期间可随时取消；
- 多显示器：每个屏幕一张覆盖层，任一屏确认或取消后各屏覆盖层一致隐藏。

Plan C——贴图、历史与设置：

- 贴图 Pin：按 F2 把图像钉在桌面——优先钉最近一次截图的整屏画面（无需框选，截图会话结束后仍可用），没有则取剪贴板图像；原生无边框置顶窗口，按住拖拽移动、滚轮缩放（10%–3200%）、Ctrl+滚轮调透明度（20%–100%）、Esc 关闭；多张贴图自动级联错开，托盘菜单可一键「关闭全部贴图」；
- 历史记录（简版）：每次截图确认即写入本地 SQLite 库并保存缩略图，全程纯本地、不上传；主面板的历史列表 UI（查看 / 删除 / 全文搜索 / 重新编辑）**已随 M2 提供**（0.3.0 起条目另带 kind 与录制时长两列语义，见 M3）；
- 主面板：启动时零窗口、后台常驻，托盘菜单「主面板」按需打开（热键注册失败时也会自动拉起并显示横幅）；
- 设置：全局热键自定义（截图 / 贴图 / 录制，修改后立即生效；与其他应用冲突时保存失败并提示）、输出格式 PNG / JPEG（JPEG 可调质量）、保存目录、开机自启、外观（跟随系统 / 浅色 / 深色）、语言（跟随系统 / 中文 / English，保存后即时生效）记忆；界面文案双语覆盖（zh-CN / en-US，key 覆盖率由 CI 门禁断言），Rust 侧文案（托盘/错误串）i18n 归后续版本；
- 基础录屏（0.2.0，M6）：0.2.0 首版按 F6 直接录制**整个主显示器**；**0.3.0 起 F6 改为进入选区模式**（拖拽 = 录该区域，Enter / 双击 = 整屏快捷确认），悬浮条显示计时并支持暂停 / 恢复 / 停止；系统声音随录（SCStream capturesAudio → AAC），暂停采用时间戳平移保证时间线无空洞；产物落 `~/Movies/HawkSnap/<日期>-<时间>.mp4`（H.264 + AAC，AVAssetWriter mux）并进历史（🎬 占位）；**麦克风混音归后续版本**（ladder 裁定，见 .superpowers/sdd/2026-10-14-hawksnap-m2-annotate-ocr-recording/task-6-report.md）。

## M2（0.2.0）——标注、OCR 与录屏

- **标注编辑器**：覆盖层动作浮条「标注」、贴图双击、历史「重新编辑」三个入口；9 类工具（选择 + 矩形 / 椭圆 / 箭头 / 画笔 / 荧光笔 / 马赛克 / 序号 / 文字），选中移动、Delete 删除、双击文字重编辑；撤销 / 重做（⌘Z / ⌘⇧Z，无步数限制）；⌘S 保存覆盖原图；画布与导出像素一致（F5 单路径绘制断言）；截图标注确认后同步剪贴板与历史，贴图标注保存即更新贴图；
- **OCR 文字识别**：入口在**标注编辑器**内（编辑器工具栏对整图识别，中英双语，PP-OCRv4 mobile 三模型，RapidOCR 管线，纯本地推理）；动作浮条「OCR」为禁用占位（未接通）；模型按需下载（首次触发，官方 release 源 + SHA256 校验，进度条可见），识别结果浮层逐行点击复制 / 全部复制 / 导出 txt，文本回填历史全文检索；引擎空闲 10 分钟自动释放内存；
- **取色器与像素标尺**：覆盖层框选全程按 C 切换取色器（放大镜取色，点击复制 HEX/RGB），选区边缘像素标尺（10px / 50px 刻度）随框选实时刷新；
- **录屏（F6）**：0.2.0 首版直接录制整个主显示器；**0.3.0 起 F6 进入选区模式**——拖拽框选要录制的区域，Enter / 双击 = 整屏快捷确认。悬浮条计时 + 暂停 / 恢复 / 停止；系统声音随录（AAC），暂停采用时间戳平移保证时间线无空洞；产物 H.264 + AAC MP4 落 `~/Movies/HawkSnap` 并进历史；失败（磁盘满 / 收尾超时）在悬浮条行内报错，不静默；
- **历史全文搜索**：历史面板支持截图 OCR 文本的中英文全文检索（SQLite FTS5，结果按时间倒序）。

验收数据（G2 空载内存 / G3 延迟 / G4 冷启动等）归档见 `docs/superpowers/bench/`；OCR 单会话峰值内存实测 ~580MB（装载 + 首推理；空闲 10 分钟自动卸载）与 72 小时录屏稳定性（G5）数据随版本验收归档。

## M3（0.3.0）——区域录制、GIF 导出、摄像头画中画、按键显示与长截图

- **区域录制（F6 选区）**：按 F6 进入**选区模式**，拖拽框选要录制的区域（Enter / 双击 = 整屏快捷确认，多显示器下只录选区所在屏）；确认后只录该区域（SCStream `sourceRect`，输出按物理像素 1:1），悬浮条显示「区域 800×600」；系统声音随录、暂停 / 恢复 / 停止与整屏录制同款；
- **GIF 导出**：录制前在覆盖层横幅上切 MP4 / GIF（**格式仅在本轮选区模式内有效**：新一轮选区模式复位为默认 MP4）；GIF 会话旁路抽帧（≥1/15s 一帧，最长边 800px 盒式降采样）→ 停止后 gifski 编码（quality 90、无限循环）落 `~/Movies/HawkSnap/*.gif` 并进历史，编码成功后删除 MP4 中间产物；**GIF 无音频**；
- **摄像头画中画（PiP）**：录制中开启摄像头 → 相机画面以圆形叠加进成片（默认右下角 240px，可拖动 / 调大小 / 隐藏），CPU 合成、相机缺席不阻塞录制；**PiP 仅作用于 MP4 成片**，GIF 不含画中画；
- **按键显示（keycast）**：录制中开启 → 屏幕角落实时显示按下的组合键（如 `⌘⇧A`）；走 CGEventTap 只读旁路（**不吞按键**，F6 停止照常触发），需辅助功能权限；同组合 100ms 内合并（长按自动重复只显示一次）；
- **长截图（滚动拼接）**：托盘「长截图」→ 拖选要拍的区域 → 滚动页面 → 提示条按 ⌘S 或点「完成」→ 模板匹配滚动拼接成长图（实测输出 20145–23912px）落保存目录并进历史（缩略图 = 首帧）；**流式拼接不留帧队列**，画布硬上界 256MB / 40000px（触顶即截断并提示）；
- **编辑器裁剪工具（M3 N0，工具栏 10/10）**：新增「裁剪」工具——拖拽框选要保留的区域，位图裁到该区域（形状随之平移 / 丢弃，撤销栈重置、工具自动复位「选择」）；⌘S 保存写回的就是裁后尺寸的 PNG；
- **历史条目元数据（M3 N0）**：历史库记录条目的 kind（`region` / `recording` / `scrollshot`）与录制时长（秒），网格按 kind 门控动作（「重新编辑」对录屏与长截图不提供）；
- **性能打点零写入（M3 N0）**：延迟打点 CSV 只在基准 / G4 模式落盘，生产运行零写入（0.1.0 / 0.2.0 的「CSV 恒写」债务收口）。

M3 验收数据（F8 GIF 编码计时 / F9 画中画时间线连续性 / F10 长截图拼接 eval / G1 体积等）归档见 `docs/superpowers/bench/2026-10-14-m3-acceptance.md`。

## 屏幕录制权限

首次截图时 macOS 会请求「屏幕录制」权限，需允许才能捕获屏幕内容；若未弹窗或截图失败，前往 系统设置 → 隐私与安全性 → 屏幕录制，为 HawkSnap（`tauri dev` 模式下为承载它的终端）开启权限，然后重启应用重试。

### 辅助功能权限（智能吸附悬停）

智能吸附的悬停高亮 / 单击选中需要「辅助功能」授权（系统设置 → 隐私与安全性 → 辅助功能，为 HawkSnap（`tauri dev` 模式下为承载它的终端）开启）。未授权时拖拽框选仍可正常使用，只是没有悬停高亮。

### F1 按键模式（媒体键兼容）

macOS 默认把 F1 当作亮度降低键（「将 F1、F2 等键用作标准功能键」未开启），此时按下 F1 不会发出普通按键事件。HawkSnap 会自动兼容这种模式，但需要二选一授权：

1. 在 系统设置 → 键盘 → 键盘快捷键 → 功能键 中开启「将 F1、F2 等键用作标准功能键」（F1 变回普通 F 键，走全局热键路径）；或
2. 保持默认（F1 = 亮度键），在 系统设置 → 隐私与安全性 → 辅助功能 中添加 HawkSnap（`tauri dev` 模式下为承载它的终端），HawkSnap 通过媒体键监听识别亮度键按下并触发截图（推荐，开箱即用，fn+F1 组合同样有效）。

两者都不满足时，应用启动会给出「提示：」横幅引导（不会静默失效）。

已知问题：macOS 14+ 上若未授予屏幕录制权限，抓屏可能静默返回仅壁纸画面而非报错。Plan D 已加入权限预检与系统设置深链引导（启动及截图时触发）；若引导后仍未生效，请按上文手动授权并重启应用。

## 已知限制

- 录屏为**全屏 + 选区两态**（F6 一次进入选区模式：拖拽 = 录该区域，Enter / 双击 = 整屏快捷确认）；**麦克风混音归 M2.1**（系统声已在轨，ladder 裁定）；录屏画面**不含本应用自身窗口**（录制悬浮条 / 贴图均不入镜，自排除裁定）；**录屏中退出应用会产生损坏的 mp4**（退出不收尾 writer，归后续版本处理）；
- **长截图只支持单轴纵向滚动**（横向滚动 / 页面缩放不支持）；**周期内容（聊天气泡、图库同构瓦片等）可能被拒绝拼接** → 该段内容缺失（宁可不拼，绝不产出重影图；eval 量化：21 个标准场景里 2 个各缺 261px / 519px）；**画布内存硬上界 256MB / 高度 40000px**（触顶即停止采集并提示，长图被截断）；匹配停滞（页面在动但内容不可测量）会停止采集并给出提示；
- **GIF 无音频**，且**不含摄像头画中画**（GIF 帧抽取旁路在 PiP 合成之前取样——GIF 语义 = 屏幕内容动图，PiP 是 MP4 成片特性）；**GIF 抽帧队列有界 32MB**（约 22 帧，超出丢最旧）→ 长录制产出的 GIF 只覆盖**收尾窗口**而非全程（MP4 产物始终是全程）；
- **画中画需相机授权**（系统设置 → 隐私与安全性 → 摄像头）；未授权 / 无设备 / 打开失败 → **PiP 静默缺席**（录制本身不受影响），相机画面仅进 MP4 成片；
- **按键显示需辅助功能权限**（CGEventTap 只读旁路），未授权时该功能不可用；修饰键单独按下（flagsChanged）不显示，只显示完整组合键；
- OCR 模型首次使用需联网下载约 60MB（官方 release 源，全程 SHA256 校验；此后离线可用）；OCR 文本检测框为轴对齐简化（det 后处理 M2 口径，倾斜文本框以矩形近似，细化归后续版本）；**OCR 不支持 Intel macOS**（ONNX Runtime 官方未发布 macOS x64 构建，Intel 机器上明确报错而非静默）；**OCR 峰值内存 ~580MB**（装载 + 首推理，空闲 10 分钟自动卸载）；
- 动作浮条「贴图」为占位（未启用；贴图经 F2 / 托盘 / 面板入口使用）；编辑器的**裁剪工具已在 0.3.0 提供**（工具栏 10/10）；
- **历史库自动裁剪**：历史条目上限 500 条（对所有 kind 平权）。裁剪时截图 / 长截图条目连带删除文件，但**录制条目只删历史行、保留 MP4 / GIF 文件**（用户的录制产物不是缓存）；用户在网格里**手动删除**某个录制条目时，文件仍会一并删除；
- **长截图条目不提供「重新编辑」**：长图可达 32MP（实测输出高 20145–23912px），编辑器画布 / 导出路径按巨幅位图走会出内存尖峰与导出超时（长图后处理归后续版本）；
- 画中画的相机 16:9 画幅经 cover-crop（居中裁方）入圆、不变形；
- **0.3.0 仅 macOS 提供二进制**：跨平台**编译**已通（M4 重构：Linux / Windows 可编译、可跑测，CI 三平台测试腿均为硬门），但跨平台**分发**未启动（Windows / Linux 的打包、代码签名与更新 feed 口径另案裁定）；非 macOS 平台的采集功能当前为「明确拒绝」而非可用（见「平台支持」一节）；
- 72 小时长时录屏稳定性（G5）自 M2 起测；
- 错误提示等 Rust 侧文案暂为中文（界面已双语，Rust 侧 i18n 归后续版本）；
- 热键冲突时仅提示保存失败，不列出占用该热键的其他应用（macOS 无公开 API），自动候选键建议留 M2 评估。

## 签名与权限说明

本地构建使用 `HawkSnapCodesign` 自签证书（证书锚定，跨构建 TCC 授权持久）。换机或重建证书后：
`security import sign3.p12` + `security add-trusted-cert -r trustRoot crt.pem`（证书文件在维护者的
`~/.tauri/codesign/`），构建后执行 `scripts/sign-local.sh` 重签。首次授权屏幕录制：系统设置 →
隐私与安全性 → 录屏与系统录音 → + 添加 HawkSnap。CI 发布构建经 `APPLE_CERTIFICATE`/
`APPLE_CERTIFICATE_PASSWORD` secrets 注入同一证书（tauri bundler 自动签名）。
