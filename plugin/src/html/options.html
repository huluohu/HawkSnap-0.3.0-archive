扩展 ID（注册 Native Messaging 宿主时需要）

运行桌面端的 scripts/install-native-host.sh --ext-id <上面的ID>，脚本会把这个 ID 写进 Chrome/Edge 的宿主 manifest allowed_origins（未列入的来源一律拒绝连接）。

HawkSnap 桌面端（Native Messaging 宿主）

宿主名： 未检测

检测会向宿主发送一个 1×1 探测帧（只落临时目录，不进桌面端历史）。「无法启动宿主」= 未运行 install-native-host.sh 或桌面端从未启动；「等待回执超时」= 桌面端可能已退出（退出即删配置）。

说明

  1. 整页截图通过 chrome.debugger 完成，期间页面顶部会显示「HawkSnap 开始调试」横幅，截图结束自动消失。
  2. 「发送到桌面端」会把截图写入 HawkSnap 的历史（来源标记为 browser）；超过浏览器单消息 4 MB 上限的整页长图会自动降级为本地下载。
  3. 本扩展只在点击工具栏 / 快捷键时截取当前页面，不做任何后台采集或上报。
